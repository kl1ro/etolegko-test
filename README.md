# Download speed

Консольный скрипт на TypeScript: делает 10 последовательных запросов к адресу, дожидается полного ответа на каждый и печатает среднее время запроса, общий объём скачанных данных и скорость скачивания.

## Запуск

Нужен Node.js 18 или новее (в нём есть встроенный `fetch`).

```sh
npm install
npm start -- <url>
```

Например:

```sh
npm start -- https://example.com/big-image.jpg
```

Без установки зависимостей скрипт запускается так:

```sh
npx tsx src/download-speed.ts <url>
```

## Структура

- `src/download-speed.ts` — точка входа: читает адрес, меряет, печатает отчёт.
- `src/command-line.ts` — адрес из аргументов командной строки.
- `src/download.ts` — 10 последовательных скачиваний и замер каждого.
- `src/http.ts` — запрос и чтение тела ответа целиком.
- `src/clock.ts` — показания часов.
- `src/report.ts` — расчёт и печать отчёта.
- `src/progress.ts` — заголовок и прогресс-бар во время теста.

## Проверка кода

```sh
npm run lint
```

Во время теста строка с прогресс-баром обновляется на месте и показывает накопленную статистику, а в конце печатается итог (числа для примера):

```
Скачивание https://example.com/big-image.jpg

[████████████████████] 10/10  среднее 412.3 мс · 28.45 МБ · 55.21 Мбит/с

Итог
  Среднее время запроса   412.3 мс
  Скачано всего           28.45 МБ
  Скорость скачивания     55.21 Мбит/с
```

## Единицы

- **Время запроса** — миллисекунды (мс), от отправки запроса до получения последнего байта тела ответа.
- **Объём** — мегабайты (МБ), 1 МБ = 1 000 000 байт.
- **Скорость** — мегабиты в секунду (Мбит/с), 1 Мбит = 1 000 000 бит. В этих единицах обычно указывают скорость интернета провайдеры и сервисы вроде Speedtest.

Скорость считается как общий объём, скачанный за 10 запросов, делённый на суммарное время этих запросов.
